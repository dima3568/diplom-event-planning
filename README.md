## Описание

EventPlanner решает проблему координации мероприятий в команде. Вместо разрозненных мессенджеров и таблиц — единая платформа, где организатор создаёт событие, приглашает участников, назначает задачи и отслеживает прогресс в реальном времени.

Каждое мероприятие включает:
- **Описание и расписание** (дата/время начала и окончания, место проведения)
- **Участников** с ролями (создатель, организатор, участник)
- **Задачи** с дедлайнами, исполнителями и статусами выполнения
- **Комментарии** — лента обсуждений
- **Журнал активности** — временная шкала всех действий

## Возможности

### Авторизация и регистрация
- Регистрация с валидацией логина, пароля и email
- Вход по логину и паролю
- Восстановление пароля (заглушка, готова к интеграции с PHPMailer)
- Кнопки-заглушки для входа через Госуслуги, Apple ID, Google (готовы к OAuth-интеграции)

### Мероприятия (полный CRUD)
- Создание, просмотр, редактирование, мягкое удаление (статус → «Отменено»)
- Поиск по названию, фильтрация по статусу и дате, постраничная навигация
- Статусы: черновик, активно, завершено, отменено
- Кнопка «Печать» с отдельным CSS для печати

### Участники
- Добавление участников по логину с назначением роли
- Таблица участников с иконками ролей
- Защита от изменения списка не-организатором

### Задачи
- Создание задач с названием, описанием, дедлайном и исполнителем
- Чек-бокс для быстрого переключения статуса «выполнена / не выполнена»
- Сортировка по дедлайну или создателю
- Фильтрация: все, активные, выполненные
- Назначение исполнителя из участников мероприятия

### Комментарии
- Лента комментариев в хронологическом порядке
- Ограничение ввода (2000 символов), счётчик символов
- Аватар-заглушки через Bootstrap Icons
- Удаление (автор или организатор)

### Админ-панель (только `admin`)
- Просмотр и управление всеми таблицами БД
- Поиск по текстовым полям
- Фильтрация по любому полю
- Сортировка по любому столбцу
- Добавление, редактирование и удаление записей

### Лендинг
- Адаптивная одностраничная страница с описанием проекта
- Ссылки на приложение, стек технологий, контакты

## База данных

SQLite-файл хранится **вне публичной директории** (`../data/app.db`), что защищает его от прямого скачивания через HTTP.

### Таблицы

| Таблица | Описание | Ключевые поля |
|---|---|---|
| `users` | Пользователи | id, username (UNIQUE), password_hash, email, created_at |
| `events` | Мероприятия | id, creator_id, title, description, start_datetime, end_datetime, location, status |
| `event_participants` | Участники мероприятия | event_id + user_id (составной PK), role |
| `tasks` | Задачи | id, event_id, creator_id, assigned_to, title, description, deadline, is_done |
| `comments` | Комментарии | id, event_id, user_id, text, created_at |
| `activity_log` | Журнал активности | id, user_id, action, entity_type, entity_id, details, created_at |

Все внешние ключи используют `ON DELETE CASCADE`.

## Безопасность

| Угроза | Мера защиты |
|---|---|
| **SQL-инъекции** | Все запросы через PDO prepared statements |
| **XSS** | `htmlspecialchars($data, ENT_QUOTES \| ENT_SUBSTITUTE, 'UTF-8')` через функцию `escape()` |
| **CSRF** | Токен из сессии, сравнение через `hash_equals()` |
| **Пароли** | `password_hash(PASSWORD_DEFAULT)` — никогда в открытом виде |
| **Несанкционированный доступ** | `checkAuth()` на каждой странице, `canManageEvent()` для действий с мероприятиями |
| **Ошибки БД** | `try/catch` → `error_log()`, пользователю — общее сообщение |
| **Дублирование POST** | PRG-паттерн (`header('Location: ...')` + `exit` после каждого POST) |
| **Удаление** | Мягкое удаление мероприятий (статус → `cancelled`), CASCADE для задач/комментариев |
| **Файл БД** | Хранится в `data/` вне корня сервера |

## Установка и запуск

### Системные требования

- **PHP 8.0+** с расширениями: `pdo`, `pdo_sqlite`, `session`
- **SQLite 3**
- Любой современный браузер

### macOS

```bash
# 1. Клонирование репозитория
git clone https://github.com/your-username/diplom-event-planning.git
cd diplom-event-planning

# 2. Инициализация базы данных
php assets/init_db.php

# 3. Заполнение тестовыми данными
php assets/seed.php

# 4. Запуск встроенного сервера
php -S localhost:8000

# 5. Открыть в браузере:
open http://localhost:8000
```

PHP обычно предустановлен на macOS. Проверить: `php -v`.

### Linux (Ubuntu / Debian)

```bash
# 1. Установка PHP и SQLite
sudo apt update
sudo apt install php8.x php8.x-sqlite3 php8.x-mbstring sqlite3

# 2. Клонирование
git clone https://github.com/your-username/diplom-event-planning.git
cd diplom-event-planning

# 3. Инициализация и заполнение БД
php assets/init_db.php
php assets/seed.php

# 4. Запуск сервера
php -S localhost:8000

# 5. Открыть в браузере:
xdg-open http://localhost:8000
```

Замените `8.x` на актуальную версию PHP (`php -v` для проверки).

### Linux (Fedora / RHEL / CentOS)

```bash
# Установка
sudo dnf install php php-sqlite3 php-mbstring sqlite

# Далее — как для Ubuntu
php assets/init_db.php
php assets/seed.php
php -S localhost:8000
```

### Windows

#### Вариант A: XAMPP

1. Скачайте и установите [XAMPP](https://www.apachefriends.org/) с PHP 8.0+
2. Скопируйте папку проекта в `C:\xampp\htdocs\event-planner`
3. Запустите XAMPP Control Panel → Start Apache
4. Откройте: `http://localhost/event-planner`

Инициализация БД через командную строку:
```cmd
cd C:\xampp\htdocs\event-planner
C:\xampp\php\php.exe assets\init_db.php
C:\xampp\php\php.exe assets\seed.php
```

#### Вариант B: встроенный PHP-сервер

1. Скачайте PHP с [windows.php.net](https://windows.php.net/download/) (ZIP Thread Safe)
2. Распакуйте в `C:\php`
3. Добавьте `C:\php` в переменную среды `PATH`
4. Откройте командную строку (Win+R → `cmd`):

```cmd
git clone https://github.com/your-username/diplom-event-planning.git
cd diplom-event-planning
php assets\init_db.php
php assets\seed.php
php -S localhost:8000
```

5. Откройте: `http://localhost:8000`

#### Вариант C: WSL (Windows Subsystem for Linux)

```bash
# В терминале WSL (Ubuntu)
git clone https://github.com/your-username/diplom-event-planning.git
cd diplom-event-planning
php assets/init_db.php
php assets/seed.php
php -S localhost:8000
```

## Деплой на хостинг

### PHP-хостинг (обычный)

1. Загрузите все файлы проекта **кроме** `data/` и `node_modules/`
2. На хостинге создайте директорию `data` **выше** публичной папки (`public_html`, `www`, `htdocs`)
3. Запустите инициализацию: `php assets/init_db.php` и `php assets/seed.php`
4. Замените все `http://localhost:8000` на реальный домен в `index.html`
5. В файлах навигации замените относительные ссылки, если корень отличается

### GitHub Pages (лендинг)

Для демонстрации лендинга без серверной части:

1. Запушьте `index.html` в репозиторий
2. Settings → Pages → Branch: `main`, folder: `/ (root)`
3. Лендинг будет доступен по адресу `https://username.github.io/diplom-event-planning/`

> **Важно:** GitHub Pages поддерживает только статические файлы. PHP-приложение нужно размещать на хостинге с поддержкой PHP 8+ и SQLite.

### Docker (опционально)

Создайте `Dockerfile` в корне:

```dockerfile
FROM php:8.2-cli
RUN docker-php-ext-install pdo_sqlite
WORKDIR /app
COPY . .
RUN php assets/init_db.php && php assets/seed.php
EXPOSE 8000
CMD ["php", "-S", "0.0.0.0:8000"]
```

Сборка и запуск:

```bash
docker build -t event-planner .
docker run -p 8000:8000 event-planner
```
